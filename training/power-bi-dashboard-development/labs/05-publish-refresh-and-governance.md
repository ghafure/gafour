# Lab 05: Publish, Refresh, and Governance

## Goal

Prepare the dashboard for controlled sharing and ongoing support.

## Tasks

1. Complete `templates/dashboard-qa-checklist.md`.
2. Save the Power BI Desktop file with a clear name and version.
3. If a training workspace is available, publish the report.
4. Configure semantic model credentials if required.
5. Set or document refresh schedule expectations.
6. Identify workspace roles and intended audience groups.
7. Document the support owner and change request process.
8. Create a short release note describing what the dashboard includes.

## If publishing is not available

Create a deployment plan that includes:

- Target workspace name.
- Content owner.
- Security groups.
- Refresh cadence.
- Data gateway needs.
- Sensitivity or confidentiality considerations.
- User acceptance testing plan.

## Deliverables

- Completed QA checklist.
- Published report link or deployment plan.
- Release note.

## Success criteria

- The dashboard has an owner.
- Refresh and access are documented.
- QA findings are resolved or triaged.
