# Lab 04: Report Design and Accessibility

## Goal

Build report pages that communicate performance clearly and accessibly.

## Tasks

1. Create an Executive Summary page.
2. Add KPI cards for Revenue, Target Attainment %, Revenue Variance, and Return Rate.
3. Add a revenue trend by month.
4. Add revenue by region or market.
5. Add revenue by product category.
6. Add slicers for date, region, product category, and customer segment as appropriate.
7. Create at least one additional page for detailed analysis.
8. Configure visual interactions so slicers and charts cross-filter intentionally.
9. Apply a consistent theme, font scale, and color meaning.
10. Review accessibility:
    - Descriptive visual titles.
    - Sufficient contrast.
    - No color-only status communication.
    - Logical tab order.
    - Alt text where available.

## Optional challenge

Create a mobile layout for the Executive Summary page.

## Deliverables

- Executive Summary page.
- At least one detail page.
- Completed accessibility notes.

## Success criteria

- Users can understand the main performance story in under one minute.
- Visuals are aligned and uncluttered.
- Accessibility issues are addressed or documented.
